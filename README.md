## Script of our Paper "The Timing of Ribosomal RNA Modification During Eukaryotic Ribosome Biogenesis". This GitHub repository contains the scripts for basecalling, read mapping and read classification for each (grouped) pre-rRNA intermediate or mature rRNA.
